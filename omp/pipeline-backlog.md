# Pipeline backlog

Durable, committed record of pipeline improvement proposals and their observed effect across
runs. `runs/` is ignored by git, so anything that must survive a run belongs here.

The improver maintains this file. A human accepts or rejects proposals that need a decision
(policy, blast radius, agent identity, objective). `skill://merge-runs` may also accept a
proposal when merging a run.
