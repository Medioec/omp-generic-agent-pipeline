# General-purpose work

This project runs a general-purpose agent pipeline. Work may be research,
analysis, automation, operations, data processing, writing, documentation, or
software changes. Code is one deliverable type, not the default.

Before acting:
- classify the work type
- name the deliverable and verification mode
- do not assume a git repository, a test suite, a diff, or a code change
- for multi-step work, use `/pipeline`; the orchestrator owns dispatch and adjudication
- do not reduce a research, automation, or operations request to a code task
